# Blockbench Offline (unofficial)

An unofficial Android app that bundles the open-source [Blockbench](https://github.com/JannisX11/blockbench) web app so it works fully offline. Not affiliated with or endorsed by the Blockbench project.

## Download
Get the latest APK from the [Releases page](../../releases/latest). When Android asks, allow installs from your browser or file manager.

## How it's built
GitHub Actions clones Blockbench, builds its web version, and wraps it with Capacitor. Each release notes the exact Blockbench commit it was built from.
